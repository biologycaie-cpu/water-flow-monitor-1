Connection help

This page uses Web Bluetooth. It needs a supported browser (normally Chrome on Android) and a secure website address (HTTPS, or localhost for testing). A normal file opened directly from Downloads may not support Bluetooth.

Water-only demonstration. Keep the electronics dry and use only a properly protected, 3.3V-safe sensor signal connection to the ESP32 GPIO.
